The end of a frame's visible interval is different from its presentation time. With evenly spaced frames beginning at zero, the last start is (frame count − 1) / fps. Container duration is not always the duration of those same video frames.

Use the commands

Choose a new output filename to preserve existing images. 0:v:0 selects the first video stream; check the stream if your file contains several tracks or cover art.

Final decoded frame

ffmpeg -i "input.mp4" -map 0:v:0 -an -fps_mode passthrough -update 1 "last.png"

This updates one PNG as the selected video stream decodes. The finished file is the last frame written, without estimating a time near the end. Processing the full clip can be slow. Adding -frames:v 1 here would stop at the first output frame.

A specific zero-based frame index

ffmpeg -i "input.mp4" -map 0:v:0 -an -vf "select=eq(n\,1)" -frames:v 1 -fps_mode passthrough -update 1 "frame-1.png"

Index 1 is the second frame: green in this fixture.

Inspect presentation timestamps

ffmpeg -i "input.mp4" -map 0:v:0 -an -vf showinfo -f null -

Look for pts_time. Our fixture reports 0, 1 and 2. The official command reference, image2 options and select filter explain these controls.

Check the output, not only the exit code.

Eight checks passed with FFmpeg 7.1.

Full decoding saved blue. Selecting frame index 1 saved green. Both PNGs were 320×180. Seeking to the three-second endpoint returned exit code 0 but created no PNG. The longer audio changed the reported duration without changing the three video timestamps.

When an earlier frame is the useful one

For a continuation, inspect the final picture for fades, blur and distorted geometry. If you choose an earlier reference, end the source clip at that same picture in your editor. Otherwise the cut leaves later frames behind before the next clip restarts from an older one.

Sharpness cannot establish correctness: inspect faces, hands, labels, edges and motion direction. PNG export cannot restore detail already lost to compression.

Not covered by this lab: variable frame rate, HDR/tone mapping, rotation metadata, corrupt input or other codec/build combinations. Use actual timestamps and inspect the output for your footage.
